Instalação Política Como funciona GitHub

Toda query passa pelo crivo.

O Crivo transforma um arquivo de política num CLI local de acesso a um Postgres de pré-produção. A IA consulta o banco por ele, e cada SQL passa pelo parser real do Postgres antes de chegar lá.

  • Deny por padrão. O que a política não cita não existe para a IA.
  • Fail closed. Coluna ambígua, nó desconhecido ou função fora da lista: recusa.
  • Executa o que validou. O banco recebe o SQL reescrito, nunca a string original.

    Uma política que cabe numa tela
    
      
    O arquivo .crivo diz o que a IA pode ler e escrever, tabela por tabela. Este é o exemplo do repositório, o mesmo que respondeu às queries acima.
    
      
    
        
    __POLICY__
    
        
    
          
    read, insert,
    update, delete
    As quatro ações. DDL, TRUNCATE, COPY, SET e afins nunca passam.
    
          
    (a, b) · except(x)
    Colunas alcançadas pela ação. Coluna bloqueada não aparece nem em filtro.
    
          
    where <expr>
    Filtro de linha: na leitura a tabela vira subquery filtrada; na escrita entra no WHERE.
    
          
    mask(col: …)
    partial, redact ou hash, aplicada no resultado.
    
          
    max N · limit N
    Teto de linhas afetadas por escrita (acima dele, rollback) e de linhas por leitura.
    
          
    deny
    A tabela some para a IA. pg_catalog e information_schema sempre somem.
    
        
    
      
    
    
    
  
    

  
    
    
    
      
    O caminho de uma query
    
      
    Parse com o pg_query, checagem contra a política, reescrita, re-parse do resultado exigindo o mesmo AST, execução em transação READ ONLY com statement_timeout e, por fim, as máscaras.
    
      
      
    
        
    
          
    erros que ensinam
    Toda recusa diz a regra, o motivo e o que seria aceito, para a IA corrigir sozinha.
    
          
    códigos de saída
    0 ok, 2 barrado, 3 SQL inválido, 4 erro do banco, 5 configuração.
    
          
    auditoria
    Cada chamada vai para ~/.crivo/logs/<nome>.jsonl, sem os dados do resultado.
    
        
    
        
    
          
    Copilot
    vendas skill install grava a skill do agent mode; skill vscode imprime o auto-approve: leitura e --dry-run livres, escrita real sempre com clique.
    
          
    MCP
    vendas mcp serve as mesmas ferramentas por stdio. A escrita real fica desligada até o servidor subir com --allow-exec.
    
        
    
      
    
    
    
  
    

  
    
    
    
      
    
        
    Melhor ainda sobre um usuário read-only
    
        
    A política funciona sozinha, mas fica mais forte como segunda camada. crivo check avisa quando o usuário de conexão tem privilégio demais, e crivo grants gera o SQL do usuário mínimo a partir da própria política, com GRANT por coluna.
    
      
    
      
    
    
  
    

  
    
    
    
      
    Instalação
    
      
    Binário pronto para cada plataforma, sem Go nem compilador C. Os links abaixo apontam sempre para o release mais recente.
    
      
    
        
        
        
      
    
      
    # Apple Silicon. Em Mac Intel, troque por crivo-macos-amd64.
curl -fsSL https://github.com/__REPO__/releases/latest/download/crivo-macos-arm64 -o crivo
chmod +x crivo && sudo mv crivo /usr/local/bin/
crivo version
    
      
    curl -fsSL https://github.com/__REPO__/releases/latest/download/crivo-linux-amd64 -o crivo
chmod +x crivo && sudo mv crivo /usr/local/bin/
crivo version
    
      
    # PowerShell: baixa para uma pasta sua e põe no PATH do usuário
$dir = "$env:LOCALAPPDATA\crivo"; New-Item -ItemType Directory -Force $dir | Out-Null
Invoke-WebRequest https://github.com/__REPO__/releases/latest/download/crivo-windows-amd64.exe -OutFile "$dir\crivo.exe"
[Environment]::SetEnvironmentVariable("Path", "$([Environment]::GetEnvironmentVariable('Path','User'));$dir", "User")
# abra um terminal novo e rode:
crivo version
    
      
    No macOS, baixar pelo terminal evita a quarentena do Gatekeeper, que recusa binários sem assinatura de desenvolvedor vindos do navegador. O Crivo é um programa de terminal: no Windows, abrir o .exe com duplo clique só mostra a ajuda.

    Do arquivo ao Copilot
    
      
    Sem banco à mão, dá para experimentar a política com um DDL: --schema-sql aceita o testdata/schema.sql do repositório ou a saída de pg_dump --schema-only.
    
      
    crivo init "postgres://svc_app@pg-hml:5432/vendas?sslmode=verify-full"   # vendas.crivo, tudo negado
$EDITOR vendas.crivo                                                   # libere o que a IA pode fazer
crivo secret set vendas                                                # senha no keychain do sistema
crivo check vendas.crivo                                               # sintaxe, semântica e schema real
crivo test vendas.crivo "SELECT * FROM clientes"                       # decisão e SQL reescrito
crivo build vendas.crivo                                               # gera ./vendas com a política embutida
./vendas skill install                                                 # skill do Copilot no workspace
